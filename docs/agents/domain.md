# Domain docs

This is a single-context repository.

Before exploring, read `docs/CONTEXT.md` and the relevant decisions in
`docs/adr/`. If a referenced document does not exist, proceed silently.

Use the glossary's terms in issues, proposals, hypotheses, and tests.
If a needed term is missing, note the gap for domain modeling. Surface
conflicts with existing ADRs explicitly rather than silently overriding them.
